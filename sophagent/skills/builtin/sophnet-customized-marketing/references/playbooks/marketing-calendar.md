# Marketing Calendar Playbook

使用场景：
- 用户说“帮我排未来两周营销计划”“做个营销日历”“哪些节点值得发”
- 用户要把节日节点、客户生日、库存上新整理成营销建议

## 工作流

### Step 1. 找近 2 周可借势节点

先读 `references/marketing-date-checklist.md`，筛出未来 2 周内可能相关的节日、电商节点、节气。

日期不固定时，用搜索确认：

```text
web_search "[当前年份] [节日名] 日期"
web_search "[当前年份] 放假安排"
```

### Step 2. 拉取业务触发点

通过 agent 编排补充：

- 客户管理 skill：未来两周生日、纪念日、可回访客户
- 库存管理 skill：应季商品、上新商品、库存充足或需要推动的商品
- 老板补充信息：行业专属节点、固定促销习惯

### Step 3. 输出营销日历

每条建议至少包含：

- 日期
- 节点/触发原因
- 目标客群
- 主推产品
- 建议渠道
- 建议发布时间
- 备注

建议格式：

```text
日期：5月8日
节点：母亲节预热
目标客群：近一年消费 2 次以上的老客户
主推产品：康乃馨花束（库存充足，¥128）
建议渠道：朋友圈 + 微信群
建议发布时间：晚上 20:00
备注：先做预热，不急着打折
```

### Step 4. 如需提醒，再联动日程提醒 skill

用户确认后，可把关键节点写入日程提醒流程，提醒用户到点发布或预热。

## 说明

- 当前日历能力以“建议生成”为主
- 如要补强提醒创建、批量写入和复用机制，再继续完善本 playbook
