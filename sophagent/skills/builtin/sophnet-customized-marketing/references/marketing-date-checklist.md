# 营销节日/节点参考清单

供 agent 在制定营销方案时参考。使用前请 `web_search` 确认当年实际日期（尤其是农历节日和法定假期调休安排）。

---

## 法定节假日（含调休，每年安排不同）

| 节日 | 大致时间 | 营销提示 |
|------|---------|---------|
| 元旦 | 1月1日 | 新年祝福、年度总结、新年新品 |
| 春节 | 农历正月初一（1月下旬~2月中旬） | **全年最重要节点**，年货/红包/拜年/团圆主题，提前2-3周预热 |
| 清明节 | 4月4日或5日 | 踏青/祭祖/短途游，注意调性，适合养生/鲜花/户外 |
| 劳动节 | 5月1日 | 五一假期，出行/消费高峰，适合各行业促销 |
| 端午节 | 农历五月初五（5月下旬~6月中旬） | 粽子/传统文化/短途出行 |
| 中秋节 | 农历八月十五（9月~10月） | 月饼/团圆/礼品，送礼消费高峰 |
| 国庆节 | 10月1日 | 黄金周，出行/消费高峰，适合各行业大促 |

> **注意**：法定假期的具体放假/调休安排由国务院每年发布，务必搜索"[年份] 放假安排"确认。

## 使用指引

1. **提前规划**：大型节点（春节、618、双十一）提前 2-4 周预热
2. **实时确认**：每次制定营销计划时，`web_search "[年份] [节日名] 日期"` 确认具体日期
3. **行业专属节点**：本清单为通用节点，如有行业专属日期（如美容师节、护士节、咖啡日等），主动询问用户并通过 SophAgent memory 工具记录（这属于业务信息，不是风格偏好，可以写入 SophAgent memory）
4. **避坑**：标注"谨慎借势"的节日（建党节、建军节、中元节等），不宜做商业化营销
5. **结合其他数据**：将节日节点与客户数据（生日、纪念日）、库存数据（应季商品、库存积压）交叉分析
