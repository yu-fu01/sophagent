# Quality Checklist

## 活动策划检查

- [ ] 活动方案是否已经用户确认后才开始生成物料？
- [ ] 活动机制是否一句话说得清？（用户发朋友圈时能直接当文案用）
- [ ] 机制数量是否不超过 3 个？
- [ ] 活动时间线是否覆盖预热 → 正式 → 收尾阶段？
- [ ] 物料清单是否覆盖了时间线上的每个发布节点？
- [ ] 不同阶段的内容是否有节奏变化（预热悬念 / 正式转化 / 收尾紧迫）？

## 文案检查

- [ ] 产品信息（名称、价格）是否来自真实数据？
- [ ] 是否符合目标平台的调性和长度要求？
- [ ] 是否有明确的行动号召（CTA）？
- [ ] 是否融入了老板的个人风格？
- [ ] 是否存在 AI 典型句式？
- [ ] 不同客群的文案是否有实质差异？
- [ ] 不同平台的文案是否分别重写？

## 海报检查

- [ ] 尺寸是否符合目标平台？
- [ ] 风格是否匹配文案主题和营销场景？
- [ ] 公众号封面是否成对生成？
- [ ] 小红书封面是否竖图 3:4？
- [ ] 是否包含敏感内容？
- [ ] 文字叠加是否清晰可读？

## 常见错误

- 没有拿业务数据就直接写文案
- 编造产品价格、电话、地址
- 所有客群使用同一条文案，只改称呼
- 各平台复用同一篇文案
- 小红书用横图做封面
- 公众号只生成头图，没生成方形预览
- 文案风格与老板风格档案矛盾
- 首次使用时没建风格档案
- 把风格信息写入 SophAgent memory 而不是 `style_profile.py`
- 强行蹭无关热点
- 忘了先确认节日日期
- 忽略安全红线
