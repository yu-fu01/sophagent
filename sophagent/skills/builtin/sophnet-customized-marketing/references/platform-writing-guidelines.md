# Platform Writing Guidelines

同一营销主题输出到不同平台时，必须重写，不能直接复用。

## 朋友圈

- 长度：2-5 行，前两行必须抓眼球
- 语气：口语化、私人感，像发给朋友看
- 结构：痛点/利益点 -> 产品信息 -> CTA
- 配图：方图 1:1 最佳
- 忌讳：不要写成硬广，不要刷屏

示例：

```text
姐妹们！！母亲节花束上新啦🌹
今年的康乃馨搭配满天星真的绝了
¥128 还送贺卡手写服务✍️
前20名下单送小花篮🌸
👉 私信我预定，送完为止！
```

## 微信群

- 长度：3-8 行
- 语气：互动感强，带行动引导
- 结构：群专属福利/消息 -> 产品亮点 -> 接龙/抢购/报名
- 技巧：可用“接龙”“扣 1”“限量”
- 忌讳：不要像公告板，价格要明确

示例：

```text
🎂 群友专享｜本周新品特价

芒果千层 6寸 原价¥168 -> 群友价¥128
提拉米苏 6寸 原价¥148 -> 群友价¥108

📌 限量各20个，周五前有效
需要的宝子直接扣数量 👇

1. 芒果千层 ×___
2. 提拉米苏 ×___
```

## 小红书

- 长度：300-800 字
- 标题：20 字内，必须有数字 + 价值点
- 语气：口语种草感，善用 emoji、数字、感叹句
- 结构：标题 -> 前 2 行抓痛点 -> 正文 -> 互动引导 -> 标签 5-10 个
- 封面：必须竖图 3:4
- 忌讳：不要书面语，不要忘标签

示例：

```text
标题：人均300搞定全脸补水💦 闺蜜都问我去哪做的

救命！这个水光针也太划算了吧！！
本来只是想做个基础补水，结果效果绝了✨

💉 做的是xx水光针（具体产品名+价格）
📍 就在xx路xx号（具体地址）
⏰ 整个过程大概40分钟

做完皮肤水当当的，第二天上妆超服帖
姐妹们有什么问题评论区问我～

#水光针 #补水 #xx美容院 #变美日记 #素颜也好看
```

## 微信公众号

- 长度：1500-5000 字
- 语气：专业有温度，不能空洞
- 结构：标题（含搜索关键词） -> 前 200 字含核心关键词 -> 多层小标题 -> 文末互动
- 配图：封面必须成对（头图 + 方形预览），正文建议每 300-500 字插图
- 忌讳：前面精彩后面注水，纯硬广无干货

## 多渠道打包

用户说“所有渠道都发一遍”时，按以下顺序分别重写：

1. 朋友圈版
2. 微信群版
3. 小红书版
4. 公众号版（需要时）
