# 美容院会员分群（数据 + 选题）

执行 `python beauty_marketing_cli.py member-segment` 或 `python member_segment.py` 获取 JSON 分群后，按下列策略选题。

## 分群定义（默认规则）

| 分群 | 规则（可调整） | 营销选题方向 |
|------|----------------|-------------|
| 高净值客户 | 储值余额 > 5000 | 私人订制疗程、稀缺档期、联名礼盒 |
| 稳定复购客户 | 1000 ≤ 余额 ≤ 5000 | 疗程升级、组合套餐、老客专属加赠 |
| 沉睡客户 | 最近到店 > 60 天或无记录 | 唤醒福利、小额体验、到店礼 |
| 新客户 | 建档 ≤90 天或到店 ≤1 次 | 二次到店锁客、会员门槛优惠 |

## 输出要求

对选定分群，必须包含：**目标 → 主推项目（引用真实服务名/价格）→ 渠道 → 3 条话术要点 → 复盘指标**。

下一步：调用 **sophnet-customized-marketing** 的 `references/playbooks/campaign-planning.md` 生成完整活动结构与物料清单。
